# 🛡 AI News Guardian

AI News Guardian is a full-stack AI-powered platform for detecting fake news, verifying claims, analyzing news articles, generating summaries, and evaluating content credibility.

## 🚀 Features

* 🧠 AI Fake News Detection
* 🌐 News URL Analysis
* 📝 AI News Summarization
* ✅ Fact Verification
* 🤖 AI Assistant Chatbot
* 🖼️ OCR Image Analysis
* 🎤 Voice-Based News Analysis
* 📄 PDF Report Generation
* 📊 Analytics Dashboard
* 📈 Interactive Charts

## 🏗️ Tech Stack

### Frontend

* React.js
* Axios
* Chart.js
* React Type Animation

### Backend

* FastAPI
* Python

### AI & NLP

* Google Gemini AI
* Transformers

### OCR

* EasyOCR
